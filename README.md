## 🖥️ Identidade Visual (Root Theme)

O projeto segue uma identidade visual única inspirada em terminais Linux e estética retro-futurista:

- **Cores**: Preto Terminal (`#0a0a0a`), Verde Neon (`#00ff41`), Ciano e Rosa Choque.
- **Tipografia**: Fontes Monospaced (`Fira Code`) e Pixeladas (`VT323`).
- **Efeitos**: Glitch, Scanlines, Digitação (Typewriter), Fica de Cursor.

## 🛠️ Stack Tecnológica

- **Core**: React.js 19 (Hooks, Context, Memo)
- **Build Tool**: Vite (Rápido e Otimizado)
- **Estilização**: Tailwind CSS v3 (Custom Config)
- **Animações**: Framer Motion & React Type Animation
- **Ícones**: Lucide React
- **Deploy**: GitHub Pages

## 🚀 Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/kauanfeelipe/meu-portfolio-novo.git

# 2. Entre na pasta do projeto
cd meu-portfolio-novo

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```
